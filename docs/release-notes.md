# 发布说明（v1.0.0 · 电视版 APK）

> 这是给用户直接用的安装包，不用会写代码也能装。

## 这个包是啥
电视版 App（`com.example.hls_proxy_player.tv`），干一件事：把你家 NAS 上的视频，
通过 FTP 直接在安卓电视上播出来，**不用装任何媒体服务器**（Plex/Jellyfin 那一套都不用）。

## 怎么装（大白话）
1. 电视和电脑连同一个 WiFi / 局域网。
2. 电视打开「开发者选项 → 无线调试」（或旧电视的“网络调试”），记下它显示的 `IP:端口`。
3. 电脑上执行（把 IP 换成你电视的）：
   ```bash
   adb connect 192.168.0.5:5555
   adb install -r hls_proxy_player_tv_v1.0.0.apk
   ```
4. 电视上找到刚装的 App 打开就行。

> 没有电脑/不会 adb？把 APK 拷到 U 盘，电视装个“文件管理器”也能直接点装。

## 装完怎么用
1. 打开 App → 「设置」→ 填你 NAS 的 FTP 主机 / 端口 / 账号 / 密码 / 根目录。
2. 回首页点「内网 FTP 资源库」就能看到剧了（需要 NAS 上有 `_map.txt`，
   不会弄就看 `docs/nas-setup.md`，有现成脚本一键生成）。

## 注意
- 这是 armeabi-v7a（32 位）电视包，适配海信 VIDAA 这类老一点 / 32 位电视。
- 手机版（arm64）另行构建。
- 仅用于播放你**自己拥有合法权利**的内容。
