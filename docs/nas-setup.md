# 家用 NAS 怎么接上这个播放器（大白话）

一句话：播放器连上你家的 FTP 后，靠一个叫 `_map.txt` 的索引文件，知道“有哪些剧、每集在哪个文件夹”。
下面教你最省事地把它搞出来。

---

## 一、你的 NAS 目录长啥样

播放器认的是这种结构（每一“集”是一个文件夹，里面是分片 `.ts`）：

```
短剧/
├── xiandai/drama_123/
│   ├── ep1/        ← 第 1 集的文件夹
│   ├── ep2/
│   └── ep3/
└── aijc/drama_456/
    ├── ep1_abc/    ← 名字带点后缀也行，只要开头是 ep 加数字
    └── ep2_abc/
```

关键点：
- 一部剧 = 一个文件夹，里面有几个 `ep` 开头的子文件夹，就是几集。
- 文件夹名字里带 `drama_数字` 最好（方便定位），不带也能扫。

---

## 二、最简单：用脚本自动生成 `_map.txt`

我们给了一个 Python 小脚本 `scripts/gen_map.py`，把上面的目录树扫一遍就出文件。

在**电脑**上跑（不是手机）：

```bash
# 先 cd 到仓库根目录
python3 scripts/gen_map.py /Volumes/你的NAS/短剧
```

- `/Volumes/你的NAS/短剧` 换成你 NAS 在电脑上挂载出来的真实路径。
- 跑完会在当前目录生成 `_map.txt`。

如果你的 FTP 根目录**不是**上面那个“短剧”文件夹，而是它的上一级，加个前缀：

```bash
python3 scripts/gen_map.py /Volumes/NAS/短剧 --root-prefix 短剧
```

生成的每行长这样（播放器就认这个）：

```
剧名=集数=相对FTP根的路径=封面URL
我的剧=5=xiandai/drama_123=https://.../cover.jpg
```

封面 URL 那一项**留空也没事**，播放器会用占位图。

---

## 三、把 `_map.txt` 放到 NAS 上

把生成的 `_map.txt` 传到你 NAS 的 FTP **根目录**下（和你的“短剧”文件夹同级）。
然后：

1. 打开播放器的「设置」，填好 FTP 主机 / 端口 / 账号 / 密码 / 根目录（`短剧` 或 `/`）。
2. 回到首页点「内网 FTP 资源库」，就能看到剧列表了。

---

## 四、不想维护 `_map.txt`？试试自动扫描（实验性）

从 1.0.0 起，`listCatalog` 在没有 `_map.txt` 时会**兜底自动扫描** FTP 目录：
自动找出带 `drama_` 的文件夹当“剧”，数里面的 `ep` 文件夹当“集”。

- 优点：零配置，丢个目录就能用。
- 注意：不同 NAS 的 FTP 列表格式五花八门，自动扫描是“尽力而为”，
  没扫到或集数不对时，还是用上面的 `_map.txt` 最稳。
- 播放能不能成，取决于你 NAS 上每集文件夹是不是真的叫 `ep1`、`ep2`……（和 `_map.txt` 里写的路径一致）。

> 小提示：自动扫描会多发几次目录列举请求，剧很多时慢一点，正常现象。
