# 为什么不用 Plex / Jellyfin？（大白话）

一句话：那些都是**媒体服务器**——你得装一个、把文件指给它、建媒体库、调转码、搞端口转发，有的还要花钱。
软件是好软件，但你只想干一件事：**“我 NAS 上有视频，想直接在电视上看”**，用它就太重了。

这个项目，**压根不装服务器**：

| | 本项目 | Plex / Jellyfin |
|---|---|---|
| 要不要媒体服务器 | 不要 | 要，得常驻跑一个服务 |
| 上手 | 填个 FTP 地址 + 一个 `_map.txt`（或者自动扫描） | 装好再配媒体库 |
| 数据去哪了 | 只在你家局域网里转 | 服务器会索引你的文件 |
| 占多大地方 | 电视上一个 APK | 一台一直开着的设备/服务 |
| 适合 | “NAS 视频直接上电视” | 大媒体库 + 远程看 |

- 想要**完整媒体中心**（海报墙、转码、手机远程） → 用 Plex。
- 想要**最短路径：NAS 文件夹 → 电视屏幕，不架任何服务器** → 用这个。

说白了，这就是给“懒得折腾、就想看自己片儿”的人准备的。
